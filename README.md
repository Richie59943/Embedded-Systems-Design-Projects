# Embedded Systems Design Repository

Welcome to my Embedded Systems Design repository. This repo contains labs, projects, notes, and experiments completed throughout the course. The focus of this class is on hardware-software interaction, embedded programming, microcontrollers, communication protocols, and real-time system design.

---

## Topics Covered

- Embedded C/C++
- Microcontroller Programming
- GPIO and Interrupts
- UART, SPI, and I2C Communication
- Timers and PWM
- Sensors and Actuators
- Real-Time Systems
- FPGA/Verilog Projects
- ESP32 Development

---

## Repository Structure

```bash
├── labs/           # Weekly labs and exercises
├── projects/       # Larger course projects
├── notes/          # Class notes and references
```
